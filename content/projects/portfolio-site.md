## Overview

A statically generated portfolio site where each project and case study is a plain Markdown file. No CMS, no database — just files on disk.

## Technical Highlights

Content is read at build time using `gray-matter` for frontmatter and `remark` for Markdown-to-HTML conversion. New pages appear automatically when a new `.md` file is dropped into the content directory.

## Status

Actively maintained and updated as new work is completed.
